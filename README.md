# gsl-simulation-animations
Everything you need to run and create the GSL animations

The GSL TBDEM file (what the animations are based off) can be found here: https://data.usgs.gov/datacatalog/data/USGS:646d0ed2d34ee02593fb50a7
Its pretty big, so it might take up to an hour to download.

Download that and use matt's code (all titled _frommatt) to create the downscaled file. Then my code will work to make the animations.

Use south_arm_flat_animation.ipynb for the south arm and na_projections_animated.ipynb for the north arm.

The animations are very large, so changing the step to decrease the quality can help your computer handle it

The simulations are in the excel files, if you want the code for how those were made, just email me at thomas@utahrivers.org
